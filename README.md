
# Attention-Enhanced HybridSN for Hyperspectral Image Classification

## Overview
This project explores an attention-enhanced HybridSN deep learning architecture for hyperspectral image classification.

The objective is to improve spectral-spatial feature extraction and investigate how attention mechanisms can improve classification performance.

## Problem Statement
Hyperspectral images contain hundreds of spectral bands, providing rich information about different materials.

However, their high dimensionality and complex spectral-spatial relationships make classification challenging.

## Proposed Approach
- Hyperspectral data preprocessing
- HybridSN baseline architecture
- Attention mechanism integration
- Model training and evaluation
- Performance comparison between baseline HybridSN and attention-enhanced HybridSN
